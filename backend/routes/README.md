# Backend API Routes

This directory defines HTTP endpoints mapping to controller handlers:

- `products.js`: `/api/products` — Product catalogue listing, filtering, search, and owner CRUD.
- `categories.js`: `/api/categories` — Categories management (Home paint, auto paint, waterproofing).
- `brands.js`: `/api/brands` — Authorized dealer brands listing and management.
- `enquiries.js`: `/api/enquiries` — Quotation requests, contact messages, and callback requests.
- `inventory.js`: `/api/inventory` — Owner-only stock adjustments, batch updates, and history logging.
- `auth.js`: `/api/auth` — Owner login, session management, and credential verification.
