# Frontend Components

Reusable UI components and modular structures for the Paint Palace showroom interface.

## Component Inventory
1. **Header & Navigation (`site-header`)**:
   - Brand identity badge (gold emblem + typography)
   - Desktop and mobile navigation links
   - Instant search input
   - Direct WhatsApp enquiry action
2. **Hero Showcase (`hero-section`)**:
   - Dual-sidebar authorized brand grids
   - High-definition 2400px showroom background
   - Interactive paint can markers (Dulux Velvet Touch, Asian Paints Royale, Berger WeatherCoat)
3. **Product Cards (`product-card`)**:
   - 600x600 high-resolution packshots
   - Pack sizes (1L, 4L, 10L)
   - Detail modal and WhatsApp prefilled enquiry
4. **Category Cards (`category-card`)**:
   - 1200x800 photographic showcases with responsive zoom
5. **Color Explorer (`color-explorer`)**:
   - Category filtering pills (Whites, Neutrals, Greens, Blues, Reds, Pinks, Purples, Darks)
   - Live room palette wall preview and clipboard hex copying
6. **Footer (`site-footer`)**:
   - Business contact, opening hours, quick links, and social links
