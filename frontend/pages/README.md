# Frontend Pages

This directory houses page-level templates and documentation for Paint Palace routes.

## Current Architecture
- **Root Entry Point**: [`/index.html`](file:///c:/Anti%20Gravity/PAINT%20PALACE/index.html) serves as the primary Vite single-page application entry point.
- **Future Multi-page Routes**:
  - `home.html` (or modular view components)
  - `products.html` (dedicated product catalogue view)
  - `color-palettes.html` (expanded interactive tinting suite)
  - `about.html` (showroom background and location showcase)
  - `contact.html` (enquiry and directions portal)
